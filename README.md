# MathKraft

**Small questions. Big discoveries.**

A neighborhood math circle for curious children in grades 1–5
in Education Hill, Redmond, Washington.

MathKraft explores mathematics through puzzles, games, patterns,
and conversation. Children are encouraged to ask questions, try
different approaches, and explain their thinking.

## The circle

- **Grades:** 1–5
- **Format:** In-person sessions
- **Location:** Education Hill, Redmond
- **Expected fee:** Approximately $5 per session
- **Schedule and venue:** To be confirmed

Parents and guardians can express interest through the Google Form
embedded on the website.

## About the organizer

Organized by **Deepak Venkatesh**, a Redmond parent and mathematics
enthusiast who has written a complete set of worked solutions to
[Gelfand’s *Algebra*](https://github.com/deepak-venkatesh/gelfand-shen-algebra) and enjoys helping
children discover mathematical ideas for themselves.

## Website

Built with HTML, CSS, and SVG artwork, and hosted on GitHub Pages.

- `index.html` — page content and embedded interest form
- `styles.css` — styling and responsive layout
- `assets/` — banner and favicon

To preview locally, open `index.html` in a browser.
An internet connection is needed to load the Google Form.
